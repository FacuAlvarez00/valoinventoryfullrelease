## Cómo agregar nuevas imágenes:

1. Coloca la imagen en esta carpeta
2. Actualiza el archivo `frontend/src/data/battlePassImages.js` con el nuevo mapeo:
   ```javascript
   'Nombre del Battle Pass': 'nombre-del-archivo.png'
   ```

## Formato recomendado:
- Tamaño: 80x80 píxeles
- Formato: PNG o JPG
- Fondo: Transparente o que combine con el tema oscuro
